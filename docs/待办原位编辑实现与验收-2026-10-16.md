# 待办原位编辑实现与验收（2026-10-16）

## 使用方式与范围

- 用户确认[原位编辑效果图](../.impeccable/mocks/todo-inline-approved.png)后，要求实现并适配所有主题，保留新增待办与拖动排序。
- 轻点目标正文，或在更多菜单中选择编辑，该条目标在原列表位置展开。编辑行内显示标题、按需展开的可选备注和取消／保存，隐藏该行的勾选与更多按钮。其他行保留原展示与顺序，列表末尾不再重复出现编辑表单。
- 保存成功后收起并显示新内容；取消恢复原显示，不写入目标。保存失败保留当前行草稿和错误提示，可重试；切换编辑对象或日期继续使用原未保存确认逻辑。
- 列表末尾新增入口保留，新增仍在末尾展开原表单；已有编辑器打开时暂不可同时新增。新增完成后追加到当日未完成组末尾。
- 目标编辑器打开时沿用原长按排序禁用规则，结束编辑后可继续拖动。普通滚动、完成／恢复、更多菜单上移／下移和删除保持原入口。

## 实现与五套主题

`pages/todo/index.wxml` 使用同一份 `goal-editor` 模板，按编辑 ID 放入对应目标行，新增时放入末尾；目标行继续使用原 `wx:key="id"`。共用现有读取、草稿保护、保存与取消方法，不改变服务、schema V3、Storage 键或备份格式。

- A「纸上拾课」：纸纹与细砖红框，纸面输入框、宋体和砖红保存按钮。
- B「秩序之间」：直角编辑面、输入框与按钮，沿用黑白红配色。
- C「奶油积木」：沿用奶油底、主题圆角和杏橙主操作。
- E「校园晴日」：沿用校园白色信息面、浅蓝输入框和绿色主操作。
- F「像素课间」：沿用蓝色阶梯边框、直角控件与像素主题操作色，正文仍为清晰系统字体。

编辑标题自动聚焦，标题和备注保留原生键盘光标避让。目标输入框的键盘高度事件控制底部 Tab 显隐；面板可完整放入可用高度时，额外按真实位置滚动，使保存／取消也位于键盘上方。长备注采用固定高度输入框内部滚动，避免无限撑高卡片；新增的备注仍沿用自动高度。页面隐藏时清理焦点／键盘展示状态，关闭编辑器时收起键盘并恢复 Tab；异步测量核对当前目标、页面可见状态和数据修订，避免过期回调拉动其它日期或编辑器。
