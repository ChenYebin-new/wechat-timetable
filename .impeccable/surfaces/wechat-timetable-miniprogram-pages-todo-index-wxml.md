# 待办每日视图

范围与模式：Operate。只优化待办这一页，让用户先选一天，再记录目标和随想；继承课表现有视觉系统，不改课表或原生双 Tab。

视觉依据：[用户已确认效果图](../mocks/todo-daily-approved.png)。图中目标和随想是合成示例，不能作为真实本地数据写入。

布局约定：居中日期与左右箭头 → 单日目标标题及完成数 → 未完成在前、已完成在后的列表 → 收起的添加入口（展开时页内标题及可选备注） → 每日随想与保存状态。没有自律养成、执行时间、截止日期、全局状态筛选或额外导航。

关键交互：历史未完成目标显示过期，但仍可补记完成；随想直接输入并自动保存。切日前先保存原日随想；目标有修改时提示放弃或继续。跨午夜时，有目标编辑器、聚焦随想或未保存内容就保持原日期，不拆分输入。

月历扩展（2026-09-17）：用户已要求按计划实现[确认月历效果图](../mocks/todo-calendar-approved.png)，精确原始生成与字数修正提示保存在图片 sidecar，图内任务和随想均为合成示例，不写入业务 Storage。默认收起，日期栏下为返回今天/展开入口；展开后白色月历卡片七列六行，周日起始，邻月可点，每天最多一个目标圆点。顶部原生日期 picker 及前后日保留；月历箭头只浏览月份。成功选日才同步高亮与展示月，普通保存/刷新不重置浏览月份；保存失败和取消编辑保留原状态，选已选日只定位月份。没有新页面、Tab、存储键、格式升级或独立计时器。

实现媒介与视觉记录：日期栏、月历卡片、原生日期按钮/圆点/选中样式、目标列表及随想均由 WXML/WXSS 实现；native 顶栏和双 Tab 由微信提供，效果图不作为运行时图片。确认图 850×1850 像素，内部 9×9 区域均值：背景 #F2F6F8、白色卡片 #FEFEFE、选中底色 #187979，与既有 #F2F5F7/#FFFFFF/#267D78 属同一青绿灰蓝体系；沿用已明确固定的项目色值，不引入生成图的纹理噪声。日期触控高度至少 44px 优先于生成图中偏小的静态格子；小屏内容允许正常纵向滚动，不缩小触控区来塞满首屏。字号继承系统中文与原有日期/目标层级，卡片 24rpx 圆角、日期面 16rpx 圆角，不增阴影或大网格线。
