# 微信课表小程序

一个使用原生微信小程序和 TypeScript 开发的个人课表工具。

第一版已实现：基于原生微信小程序 + TypeScript 的七天周课表，支持课程新增、编辑、删除、同天同节次冲突检查，数据保存在微信本地 Storage。

## 第一版功能（已实现）

- 展示周一至周日七列课表，左侧固定九节课及对应时间。
- 连续多节课程显示为一张跨行课程卡片。
- 手动新增、编辑和删除课程（删除前二次确认）。
- 检查同一天、同一节次的课程冲突，编辑时排除课程自身。
- 使用微信本地 Storage 保存课程，关闭重进后数据仍在。
- 空课表时展示新增课程引导。
- 第一版暂不包含：待办事项、文件或教务系统导入、账号登录、云同步、教学周/单双周、消息提醒。

## 本地运行

1. 克隆仓库。
2. 在 `wechat-timetable` 目录安装依赖：

   ```powershell
   cd wechat-timetable
   npm install
   ```

3. 打开微信开发者工具，导入 `wechat-timetable` 目录。
4. 使用项目成员自己的微信扫码登录并编译。

如果需要使用正式 AppID 预览或真机调试，仓库管理员还需要在微信公众平台将协作者添加为项目成员。GitHub 仓库权限与微信小程序权限分别管理。

## 协作方式

- `main` 保存已经检查、可以继续测试的代码。
- 每项功能或修复使用独立分支。
- 开发完成后通过 Pull Request 审查并合并。
- 只暂存当前任务涉及的明确文件，不使用 `git add .` 或 `git add -A`。
- 用户可见功能、依赖、启动方式或重要修复发生变化时，同步更新 README 和 `CHANGELOG.md`。

第一版的负责人、交付目标和验收条件见[第一版开发任务分工](./第一版开发任务分工.md)。详细协作规则见[微信课表小程序协作开发规范](./微信课表小程序协作开发规范.md)，开发、测试和上线步骤见[微信课表小程序开发与上线指南](./微信课表小程序开发与上线指南.md)。

## 敏感信息

不要提交或发布以下内容：

- AppSecret、Access Token 或云开发密钥。
- 微信代码上传私钥。
- `project.private.config.json`。
- 管理员二维码、登录凭证和备案材料。
- 与开发无关的个人信息。
