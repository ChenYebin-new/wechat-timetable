# 微信课表小程序

一个使用原生微信小程序和 TypeScript 开发的个人课表工具。

已实现：基于原生微信小程序 + TypeScript 的七天周课表，支持课程新增、编辑、删除、冲突检查、数据备份与恢复（V1.0.1），以及学期与教学周（V1.1）。数据保存在微信本地 Storage。

## 第一版功能（已实现）

- 展示周一至周日七列课表，左侧固定九节课及对应时间。
- 课表主页采用“今日安排概览 + 一周课表”的纵向布局，七天保持同屏显示。
- 连续多节课程显示为一张跨行课程卡片。
- 手动新增、编辑和删除课程（删除前二次确认）。
- 检查同一天、同一节次的课程冲突，编辑时排除课程自身。
- 使用微信本地 Storage 保存课程，关闭重进后数据仍在。
- 空课表时展示新增课程引导。
- 数据管理（V1.0.1）：导出课表为 JSON 文本、粘贴并校验导入、覆盖或合并、恢复最近自动备份。
- 学期与教学周（V1.1）：设置第一教学周星期一与学期总周数（1–30）；课表顶部显示当前"第 N 周"，支持上一周/下一周/直接选周；课表只显示所选周实际有课的课程。
- 课程周次（V1.1）：每门课程可选全部周、单周、双周或指定周次。
- 冲突判断（V1.1 升级）：星期、节次、周次三者都重叠才算冲突。
- 暂不包含：待办事项、文件或教务系统导入、账号登录、云同步、消息提醒。

## 本地运行

1. 克隆仓库。
2. 在 `wechat-timetable` 目录安装依赖：

   ```powershell
   cd wechat-timetable
   npm install
   ```

3. 打开微信开发者工具，导入 `wechat-timetable` 目录。
4. 使用项目成员自己的微信扫码登录并编译。

如果需要使用正式 AppID 预览或真机调试，仓库管理员还需要在微信公众平台将协作者添加为项目成员。GitHub 仓库权限与微信小程序权限分别管理。

## 数据备份与恢复

1. 在课表主页点击“数据”。
2. 点击“复制课表 JSON”，把备份文本保存到可信位置。
3. 恢复时将完整 JSON 粘贴到输入框，点击“解析并预览”。
4. 核对预览中的课程、重复和冲突数量，再选择覆盖或合并。

覆盖、合并和恢复前都会保存当前课表（V2，含学期与周次）作为最近自动备份。格式错误、字段非法或版本不兼容的数据不会写入；导入旧版（V1）备份时会先要求确认学期设置，再按"全部周"升级为 V2；如果检测到更高版本的本地课表，本版本会停止修改并提示使用更新版本。

备份服务的自动化测试使用 Node.js 24 自带能力，不增加第三方依赖：

```powershell
cd wechat-timetable
npm test
```

## 协作方式

- `main` 保存已经检查、可以继续测试的代码。
- 每项功能或修复使用独立分支。
- 开发完成后通过 Pull Request 审查并合并。
- 只暂存当前任务涉及的明确文件，不使用 `git add .` 或 `git add -A`。
- 用户可见功能、依赖、启动方式或重要修复发生变化时，同步更新 README 和 `CHANGELOG.md`。

第一版的负责人、交付目标和验收条件见[第一版开发任务分工](./docs/第一版开发任务分工.md)。下一阶段的数据备份恢复、学期与教学周开发要求见[V1.0.1 与 V1.1 开发任务书](./docs/V1.0.1与V1.1开发任务书.md)。详细协作规则见[微信课表小程序协作开发规范](./docs/微信课表小程序协作开发规范.md)，开发、测试和上线步骤见[微信课表小程序开发与上线指南](./docs/微信课表小程序开发与上线指南.md)。

## 敏感信息

不要提交或发布以下内容：

- AppSecret、Access Token 或云开发密钥。
- 微信代码上传私钥。
- `project.private.config.json`。
- 管理员二维码、登录凭证和备案材料。
- 与开发无关的个人信息。
