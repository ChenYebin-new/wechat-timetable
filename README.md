# 微信课表小程序

一个使用原生微信小程序和 TypeScript 开发的个人课表工具。

项目目前处于初始化阶段，仓库中是微信开发者工具生成的 TypeScript 基础模板，课表页面和课程管理功能尚未实现。

## 第一版范围

- 展示周一至周日七列课表。
- 显示节次和对应时间。
- 手动新增、编辑和删除课程。
- 检查同一天、同一节次的课程冲突。
- 使用微信本地 Storage 保存课程。

第一版不包含待办事项、文件或教务系统导入、账号登录、云同步和消息提醒。

## 项目目录

```text
WechatCode/
├─ wechat-timetable/                 # 微信开发者工具项目
│  ├─ miniprogram/                   # 小程序源代码
│  ├─ typings/                       # 微信 API 类型定义
│  ├─ package.json
│  ├─ project.config.json            # 团队共享项目配置
│  └─ tsconfig.json
├─ 第一版开发任务分工.md
├─ 微信课表小程序开发与上线指南.md
└─ 微信课表小程序协作开发规范.md
```

`project.private.config.json` 是每位开发者自己的微信开发者工具配置，不提交到仓库。

## 本地运行

1. 克隆仓库。
2. 在 `wechat-timetable` 目录安装依赖：

   ```powershell
   cd wechat-timetable
   npm install
   ```

3. 打开微信开发者工具，导入 `wechat-timetable` 目录。
4. 使用项目成员自己的微信扫码登录并编译。

如果需要使用正式 AppID 预览或真机调试，仓库管理员还需要在微信公众平台将协作者添加为项目成员。GitHub 仓库权限与微信小程序权限分别管理。

## 协作方式

- `main` 保存已经检查、可以继续测试的代码。
- 每项功能或修复使用独立分支。
- 开发完成后通过 Pull Request 审查并合并。
- 只暂存当前任务涉及的明确文件，不使用 `git add .` 或 `git add -A`。
- 用户可见功能、依赖、启动方式或重要修复发生变化时，同步更新 README 和 `CHANGELOG.md`。

第一版的负责人、交付目标和验收条件见[第一版开发任务分工](./第一版开发任务分工.md)。详细协作规则见[微信课表小程序协作开发规范](./微信课表小程序协作开发规范.md)，开发、测试和上线步骤见[微信课表小程序开发与上线指南](./微信课表小程序开发与上线指南.md)。

## 敏感信息

不要提交或发布以下内容：

- AppSecret、Access Token 或云开发密钥。
- 微信代码上传私钥。
- `project.private.config.json`。
- 管理员二维码、登录凭证和备案材料。
- 与开发无关的个人信息。
