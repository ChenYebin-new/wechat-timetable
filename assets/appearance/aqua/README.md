# 清透晴空视觉依据

`approved-timetable.png` 是用户于2026-10-25确认的课表效果图，作为第六套外观 `aqua` 的视觉标准。图中的课程及日期为设计示例，不用于初始化个人课表。

页面由真实 WXML／WXSS 组件实现；效果图仅归档，不进入小程序运行时包。运行时图标位于 `wechat-timetable/miniprogram/assets/appearance/*-aqua.svg`。

图由内置 imagegen 根据用户提供的参考截图生成。提示要求保留浅青薄荷渐变、通透周次日期栏、白色七日课表、横向虚线、浅彩课程底与左侧色条；名称适配“拾课课表”，底部按现有路由使用课表／待办两入口。完整规范见根目录 DESIGN.md。
